# Symbiosis Quantum Club — Project Rules & Guidelines

Welcome to the Symbiosis Quantum Club Web Application project.

## Key Rules & Constraints

1. **Tech Stack**:
   - **React 18+** with Vite
   - **Tailwind CSS** for all styling

2. **No Custom CSS Files**:
   - **NEVER generate new `.css` files or directories**.
   - All styling MUST be implemented using inline Tailwind CSS utility classes in React JSX components.

3. **Design System & Theme**:
   - Quantum spectrum palette: Dark Obsidian `#070a08`, Emerald `#34d399` / `#10b981`, Cyan `#06b6d4`.
   - Use glassmorphism (`backdrop-blur-xl bg-[#121513]/90`), subtle micro-animations, and clean typography.

4. **Build Integrity**:
   - Always run `npm run build` after changes to verify zero compilation errors.
